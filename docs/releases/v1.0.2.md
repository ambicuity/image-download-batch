## Image Download - Batch v1.0.2

Maintenance release.

- Removed the unused `declarativeNetRequest` permission. The code that would have used it (Referer rules) was never called, so behavior is unchanged and the extension now requests only the permissions it uses.
- Release automation updated to Node.js 24 GitHub Actions.

Includes all fixes from [v1.0.1](https://github.com/ambicuity/image-download-batch/releases/tag/v1.0.1).
