## Image Download - Batch v1.0.3

Fix release — 12 defects found in a full audit of the extension runtime, each with
a regression test that fails on the previous code.

### Download naming

- **Downloading a single image from its card now numbers the file correctly.** Every
  individually downloaded image was named `imgi_1_<name>`; it now uses the image's
  real position on the page (`imgi_2_…`, `imgi_3_…`, …).
- **The right-click "Download all images" action now honours your download
  options.** It previously ignored the custom-name template, the subfolder and
  the file extension, and saved files under Chrome's own names.
- **Saving download options from the menu no longer switches the "Specify
  Download Options" preference on or off**, and no longer wipes the saved
  naming settings.
- **The card's Download button now uses the options shown in the download menu**,
  matching the Convert button beside it.
- **ZIP archives are named with your preferences** and are no longer nested in the
  subfolder twice.

### Selection and downloads

- **Images you selected are no longer lost when a filter hides them.** Previously
  a hidden selection was dropped from the download, and if *every* selected image
  was hidden the extension downloaded every visible image instead.
- **"Download all images" now asks before starting a large batch** instead of
  silently downloading hundreds of files. The "Do not show many files warning"
  preference still skips the prompt.

### Interface

- **The filter menus (Size, Type, Layout, Sort) now close when you pick an
  option** instead of staying open over the results.
- **The Preferences shortcut badge now shows the shortcut for your platform**
  (Ctrl+Shift+Y on Windows and Linux, ⇧⌘Y on macOS) and opens Chrome's
  shortcut settings when clicked.

### Page highlighting

- **Selected images are highlighted on the page even with "Prefer full
  resolution" enabled.** The full-resolution URL replaced the page's own URL, so
  nothing matched and no outline appeared.

### Internal

- The download-naming logic moved into a shared module, so the popup, the ZIP
  builder and the right-click action all produce identical file names.
- The release package and CI now include the new module and its test suite.

Includes all fixes from [v1.0.2](https://github.com/ambicuity/image-download-batch/releases/tag/v1.0.2).
