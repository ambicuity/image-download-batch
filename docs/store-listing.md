## Detailed description

```
Image Download - Batch finds every image on a web page and lets you download them all in one go — filtered, renamed, and in the resolution you actually want. Everything runs locally in your browser: no accounts, no servers, no tracking.

━━ WHAT IT DOES ━━

• Smart discovery — pulls images from <img> tags, srcset and <picture>, CSS backgrounds, SVGs, shadow DOM, lazy-loaded content, Open Graph/Twitter cards, video poster frames, and image <link> tags.

• Batch download — grab images individually or as a single ZIP archive.

• Prefer full resolution — one toggle rewrites thumbnail URLs to their largest originals (Cloudinary, Shopify, WordPress, Imgix, retina @2x/@3x) so you get the real image, not the preview.

• Custom filename templates — name your files with tokens like {name}, {index}, {index:3}, {domain}, {date}, {year}{month}{day}, and {timestamp}.

• Advanced filters — filter by size, file type, or URL pattern; sort and select exactly what you need.

• Image conversion — convert between WEBP, PNG, and JPEG on the fly.

• Copy & export — copy the URLs of selected (or all) images to your clipboard, or export them as a .txt list.

• Right-click "Download all images on this page" — the whole page in one click.

• Side panel mode — dock it in Chrome's side panel for persistent access while you browse.

• Keyboard shortcuts — Ctrl/Cmd+Shift+Y to open; in the popup: Ctrl/Cmd+A select all, C copy URLs, E export.

━━ PRIVACY FIRST ━━

100% local processing. This extension does NOT:
• send any data to external servers
• include analytics or tracking
• require an account or login

━━ PERMISSIONS ━━

Access to page content is used only to read image URLs on the page you're viewing so it can download them. Nothing leaves your browser.

Made by Ritesh Rana.
```
