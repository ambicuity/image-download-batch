# Image Download - Batch

> Discover, filter, and batch download every image on any web page.

## Features

- **Smart Image Discovery** — Finds images from `<img>` tags, CSS backgrounds, `srcset`, SVGs, shadow DOM, and lazy-loaded content
- **Advanced Filters** — Filter by size, file type, or URL pattern. Sort and select exactly what you need
- **Batch Download** — Download images individually or as a ZIP archive with custom file naming
- **Image Conversion** — Convert between WEBP, PNG, JPEG, and other formats on the fly
- **Side Panel Mode** — Use as a popup or dock it in Chrome's side panel for persistent access
- **100% Private** — All processing happens locally in your browser. No data sent externally. No tracking. No analytics

## Installation

1. Clone or download this repository
2. Open `chrome://extensions` in Chrome
3. Enable **Developer mode** (top right)
4. Click **Load unpacked** and select this directory
5. Click the extension icon or press `Ctrl+Shift+Y` (Mac: `⌘⇧Y`)

## Keyboard Shortcut

| Platform | Shortcut |
|----------|----------|
| Windows/Linux | `Ctrl + Shift + Y` |
| macOS | `⌘ + Shift + Y` |

## Privacy

This extension processes everything locally in your browser. It does not:
- Send any data to external servers
- Include analytics or tracking
- Require an account or login
